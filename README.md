# 日本語化（CoC7）
FoundryVTTのシステム Call of Cthulhu 7th edition に関連する以下のパッケージに付属する辞典を日本語化するモジュールです。

- [Call of Cthulhu 7th edition](https://foundryvtt.com/packages/CoC7)
- [Call of Cthulhu® - Core Content](https://foundryvtt.com/packages/cha-coc-fvtt-en-keeperitems)
- [Call of Cthulhu® - Quick-Start Rules](https://foundryvtt.com/packages/cha-coc-fvtt-en-quickstart)
- [Call of Cthulhu - FoundryVTT - Investigator Wizard](https://foundryvtt.com/packages/call-of-cthulhu-foundryvtt-investigator-wizard)

下記ライセンスに基づき、ルールブックの所有を前提にその参照を行いやすくすることを目的としたソフトウェアであるため、名称等の翻訳のみを提供し詳細な説明は意図的に含めていません。

現在はプロトタイプ版であり未訳の部分が多く、更新を高頻度で行うため、セッションでの使用はまだおすすめしません。

## インストール方法
FVTTの「モジュールを入手」メニューを開き「URLを指定」にて、以下のURLを入力しインストールしてください。

v13でのみ動作確認をしています。

```
https://github.com/ryotai-trpg/coc-babele-ja/releases/latest/download/module.json
```
